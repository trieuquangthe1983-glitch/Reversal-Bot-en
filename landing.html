LTR confluence strategy

Liquidity-Trap Reversal runs alongside. When both fire same-side, a "confluence" trade is taken with tighter SL and wider TPs.

FAQ

What if the bot doesn't work for me? Refunds? ▼

Within 7 days of purchase, email dht.io.vn@gmail.com with the issue and your tx hash. We'll work it out — refund or transfer to a different machine. After 7 days, we'll still help diagnose, but refunds are case-by-case.

Is the bot guaranteed to be profitable? ▼

No, and anyone claiming otherwise is lying. The bot is built on rigorous backtests (2 years of data, 10 tokens) but markets adapt. We document honest failure modes in the README. Start with the trial and DRY_RUN mode to see how it performs in current conditions.

Can I run it on a VPS so it trades 24/7? ▼

Yes — the bot is a standard Python app, runs on any Windows VPS (Windows Server, Vultr, Contabo, etc.). One-machine license binding means you'll activate on the VPS specifically. If you need to move later, email support for a free transfer.

What exchanges do you support? ▼

OKX (testnet + mainnet) and Gate.io (live, Unified Account with isolated margin at 15× default). Both via the official ccxt library. Adding new exchanges is a small code change — email support if you need a specific one.

Does the bot send my API keys somewhere? ▼

No. API keys are encrypted with Fernet + PBKDF2 (310k rounds) using a vault password that only exists in your machine's RAM. The bot calls the exchange directly from your machine. The only outbound traffic is to BSC/Tron RPC (for license verify) and the license server (for activation + 6-hour heartbeat).

What if the license server goes down? ▼

Bot keeps running offline for up to 7 days from last successful heartbeat. Server uptime is monitored 24/7 — see live status link at the bottom. If we have an outage, your bot doesn't stop.

Why USDT only? No credit card? ▼

Three reasons: (1) crypto traders already have USDT, no friction. (2) Lower fees passed to you — no Stripe 3% + currency conversion. (3) Self-custody — we never see your card details, you keep custody until the moment you click Send. If you don't have USDT, easiest is Binance → buy USDT → withdraw to your wallet (DON'T withdraw directly to our wallet from Binance — Binance subtracts a fee).
